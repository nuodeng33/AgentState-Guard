- StateDB 事务增加显式 `immediate=False` 选项，Work 的任务、要求、成果、现场、关联 Agent、列表及工作详情使用延迟读取快照。命令写入继续默认 `BEGIN IMMEDIATE`，未扩大写权限或修改数据库结构。
- 新回归在独立 SQLite 写事务未提交时，经真实 HTTP 查询七类 Work 内容；修复前任务 503，修复后读取已提交内容通过。后端事务、Work、迁移、执行及交付共 **93 passed**；前端卡片与返回 **16 passed**；TypeScript、产品构建、Ruff 和空白检查通过。
- 卡片错误区分服务忙、引用失效和连接／认证失败，不显示原始异常；用户重试只重新读取正文，不重放写操作。
- 确认无活动执行或恢复后，只重启原预览加载修复。真实 Chrome 无接口夹具、无数据修改，连续四次打开用户 Work：要求和任务均有正文，任务接口四次 200，无失败请求或页面异常。结果与截图为 `live-task-card-fixed.json`、`live-task-card-fixed.png`。
