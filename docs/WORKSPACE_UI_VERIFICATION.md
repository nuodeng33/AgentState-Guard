## 本次实现

- Work 使用独立全屏外壳，隐藏总览与 Guard 侧栏。默认只显示居中的核心；关系由用户按需分批展开，保留原关系视角。默认场景去掉第二条顶部工具栏，环境、设置等入口位于小型底部坞。
- 关系空间平移、缩放、节点移动、适应画布；点击内容进入聚合工作台。普通任务与成果不伪装成 Agent 泡泡。
- 聚合画布显示真实正文，关联内容按需展开；支持卡片移动、尺寸、内部滚动与画布缩放。保存为空的现场提供直接打开要求和内容库入口；恢复空工作台可放入要求与最新一份成果并重新定位。
- “继续工作台”保持已有视角；专注阅读独占屏幕，退出还原现场与原卡片按钮焦点；Esc 和可见按钮逐层返回。
- 保存会话按 Work 隔离。返回不等待保存成功，失败草稿在当前页面会话内保留；异步响应不会串到另一项工作。原请求重试和显式冲突处理仍保留，浏览器关闭会提醒未保存现场。内存草稿不能宣称已跨刷新保存。
- 工作直链读取失败后清除失效选择，加载实际工作列表。去往 Guard 后再回 Work 保持挂载与布局，隐藏时停止 Work 的快捷键和 3D 渲染。
- 3D 观赏按需加载本地 Three.js，以金属薄壳核心和实际 Agent 薄膜泡泡显示同源事实。标签随对象投影缩放；任务关联默认收起，展开后显示明确关联的任务与连线，点击任务回到二维正文。支持暂停、旋转、重置与返回；WebGL 失败保留事实和返回入口。
- 本机发现接入现有可验证观测，支持明确关联 Agent 到 Work、勾选关联任务与查看依据。二维与三维复用保存的任务 ID；普通责任人文本不推断 Agent 身份。进程 RUNNING 与用户关联均不证明正在执行任务，执行活动明确为未知。
- 保留旧 schema-1 现场与幂等摘要；视图引用必须属于该工作，关闭卡片不删除内容，移动节点不改变依赖。
- 产品总规格、架构、需求、接口合同及原实施计划已同步当前切片状态。
