This is a pre-implementation readiness matrix. `READY`, `PARTIAL`, `MISSING`,
and `BLOCKED` are planning states, not acceptance results:

- `READY`: a current executable verifier covers the required path/level; it
  still must run at the future final P9 SHA.
- `PARTIAL`: relevant implementation/tests exist, but a required binding,
  integrated path, level, or evidence envelope is incomplete.
- `MISSING`: the required product path or executable verifier does not exist.
- `BLOCKED`: a named future SHA, artifact, host, or prerequisite is required
  before valid execution can occur.

Artifact hashes and performance values are provenance/observations, not an
extra evidence level. A GitHub-hosted Windows job is L3, not L5.
