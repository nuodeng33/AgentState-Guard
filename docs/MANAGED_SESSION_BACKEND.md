# ASG 受管会话：能力与接口

更新：2026-10-15（工作级反馈与上下文接入；提供方实测版本仍为 9 月 30 日历史记录）。验收记录见 [MANAGED_SESSION_ACCEPTANCE_20260930.md](MANAGED_SESSION_ACCEPTANCE_20260930.md)。

## 对象与边界

Work 保存要求、任务、成果与交付。`work_sessions` 绑定已核验的来源、程序、会话库、目录和原生会话；`work_runs` 保存一次执行的固定输入和结果；`work_run_events` 保存有序事件。迁移 18、19 追加到既有 StateDB，命令继续使用 `work_requests`。

外部发现及会话读取保持只读。用户明确授权创建或继续受管会话后，Core 才持有该会话的协议连接。继续历史会话建立 ASG 管理的连接，不能据此接管其他窗口的 PID。进程、cwd、人工关联均不证明任务执行或修改作者。

执行前冻结要求版本、所选任务及依赖、显式上下文、目录身份、授权和真实基线。上下文支持同 Work 的要求、成果、文件版本及复核反馈。每个会话和每个目录同时只允许一个活动执行；包括只读运行，首版采用保守互斥。恢复沿用已有预览、备份、操作日志及对账流程，与受管执行互斥。

## 当前提供方能力

| 环境／提供方 | 实测结果 | 开放范围 |
| --- | --- | --- |
| Windows Codex 0.159.0 | 握手、目录沙箱、真实运行、流式输出、续接、取消、精确状态对账通过 | 已核验目录内的只读及写入运行 |
| Docker Codex 0.147.0 | 握手通过；真实沙箱探测因 bwrap namespace 限制失败 | 保留发现和会话读取；受管运行拒绝，返回权限能力原因 |
| Docker kimi-code 0.29.2 ACP | 握手确认 list、load、resume；没有可验证的只读／写入目录约束 | 保留发现和会话读取；受管运行返回 `EXECUTION_ACP_SCOPE_UNENFORCED` |
| 用户 WSL | 当前没有已运行、可验收的用户发行版 | 未验收；不唤醒发行版完成测试 |

原生 fork 已实现格式和身份校验，尚未完成真实端到端验收，页面首版只提供新建与继续。Zcode、CloudCLI 等观察来源不会自动变成执行器。

Codex 使用所选目录的 `read-only` 或 `workspace-write` 沙箱，网络关闭，排除额外临时写入范围。按会话禁用继承的 MCP、Apps、Web 搜索和多 Agent 扩展。当前权限升级请求只允许拒绝或取消，避免批准后绕过已验证目录；问题回答另走一次消费接口。没有修改提供方配置文件、安装依赖、登录或提权。

## 本地 API

以下路径相对于 `/api/v1/works/{work_id}`，沿用本地会话鉴权，不加入 Device Link。

| 方法／路径 | 行为 |
| --- | --- |
| `GET /execution-summary` | 当前 Work 的活动运行及每会话最新失败／中断；分状态计数、最多 100 项（默认 20），返回截取标记、要求版本和查询时间；不读取输入或输出正文 |
| `GET/POST /sessions` | 分页查询；创建明确的程序、库、目录与授权绑定 |
| `GET/PATCH /sessions/{id}` | 状态、能力；修改 ASG 昵称 |
| `POST /sessions/{id}/connect` | 显式重新授权并复核身份，继续确切原生会话 |
| `POST /sessions/{id}/archive` | 归档管理记录，活动运行时拒绝；原生历史保留 |
| `GET/POST /sessions/{id}/runs` | 分页查询；冻结输入、保存基线并排队执行 |
| `GET /runs/{id}` | 完整或 `view=summary` 状态、原生身份、目录版本结果 |
| `GET /runs/{id}/events` | `after`、`limit` 游标分页；`stream=true` 或 SSE Accept 订阅 |
| `POST /runs/{id}/responses` | 回答明确问题或处理明确审批；绑定事件、连接代次与动作引用 |
| `POST /runs/{id}/cancel` | 持久取消意图；确认停止后才进入终态 |
| `POST /runs/{id}/reconcile` | 按确切原生 turn ID 查询终态，不重发输入 |
| `POST /runs/{id}/artifacts` | 显式保存所选 TEXT 输出或用户编辑内容，保留来源引用 |
| `GET/POST /submissions` | 固定要求、成果及目录版本，登记责任人 |
| `POST /submissions/{id}/reviews` | 保存复核决定和反馈 |
| `POST /submissions/{id}/acceptances` | 工作负责人登记验收决定和依据；旧要求不能用于当前验收 |

运行查询、事件、取消、回答及保存成果也支持既有 `/sessions/{session_id}/runs/{run_id}/…` 路径，两类路由调用同一业务入口。

写请求使用 UUID `request_id`。创建会话、交付及复核使用 Work 修订号；启动执行及会话操作使用 session 修订号。相同请求返回原收据，改变内容必须使用新请求。`responses` 另需 `event_seq`、`action_ref` 和回答内容。客户端不能传入任意命令行或原生 RPC 方法。

会话状态：`CONNECTING`、`READY`、`DISCONNECTED`、`UNAVAILABLE`、`UNCERTAIN`、`ARCHIVED`。

运行活动状态：`QUEUED`、`DISPATCHING`、`RUNNING`、`WAITING_APPROVAL`、`WAITING_INPUT`、`CANCELLING`、`FINALIZING`、`UNCERTAIN`。终态：`COMPLETED`、`FAILED`、`CANCELLED`、`INTERRUPTED`。`FINALIZING` 表示提供方已结束但目录结果仍在保存；`UNCERTAIN` 持续保留占用，不能作为成功或再次派发的依据。

SSE 事件先落库再发送，使用单调序号；重连从 `after` 补载。正常终结发送 `done`，包括历史是否完整；订阅错误明确发送 `error`。页面关闭不取消 Core 持有的运行。

## 可靠性与保留

派发前写入意图。回执丢失后不重发输入或审批。启动时把确定未发送的运行标为中断，把可能已发送的运行标为待对账；已经持久化的有效提供方终态继续收集文件结果。原生历史回放不会成为新执行证据。对账使用确切 turn ID，分页有上限，无法核验时保留未知状态。

默认事件详情保留 30 天，每 run 32 MiB、全局 512 MiB 逻辑预算，单 run 另预留 1 MiB 控制事件空间。输入最多 64 KiB，单事件最多 256 KiB；超长输出分块或明确截断，不挤掉取消、审批和终态。每五分钟或空间压力时清理；活动运行、交付及成果引用的运行保留完整来源。其余过期运行保留摘要、摘要哈希和控制证据，标为 `SUMMARY_ONLY`。这不是数据库物理磁盘硬上限。

文件变化使用既有 ProtectionService 保存真实版本，仍标为 `UNATTRIBUTED`；运行目录结果表示观察范围内的变化，不能证明每一笔修改由 Agent 创建。运行结束、文件保存、复核与验收分别记录。负责人仍是既有本地责任标签，不是新增的多用户身份系统。

## 页面接入

Work 的“更多操作”按需打开会话与交付。保存输出后复用原有成果卡片。交付目录来自 Work 的目录关联，手工工作无需先创建受管会话。运行日志展示最多 500 条，交付输出支持分页补载；差异查找最多扫描 500 个目录版本，超过范围明确提示不可用。草稿在当前页面内存中保存，不承诺关闭浏览器后的草稿恢复。

工作级反馈在页面可见时每轮请求结束后间隔 3 秒读取摘要，请求在途不重叠；隐藏页面暂停、恢复可见后立即读取。这是采样间隔，不是端到端延迟保证。无需打开会话面板即可看到运行／待处理提示，点击进入明确的 session/run。失败保留上次结果并标记更新失败，不显示为空；没有活动或异常时隐藏入口。会话详情额外返回所选保护目录 `scope_root`，不返回完整身份与授权结构。

本次输入默认附带当前要求和绑定任务。额外上下文由用户明确勾选成果版本、复核记录，或所查看运行的已保存文件版本；最多 32 项。文件差异与上下文选择共用有界版本读取。非文本、已清理、跨 Work 或其他无效引用由后端拒绝，草稿保留。继续原生会话会使用提供方原有上下文，不能据此承诺上下文已清空。

Work 摘要发现要求有更新时重新读取工作内容；已有运行保留原要求快照。输入草稿保留原版本并阻止直接发送，用户确认“下一次执行采用当前要求”后方可继续。运行中的新指令只是未发送草稿，不实现自动排队或 steer；用户需等待执行结束，或请求停止并确认后再发送。提问／审批自动进入可见区域，正在编辑输入时不抢阅读位置。

## 尚未验收

跨环境真实受管运行、原生 fork、提供方被操作系统强杀时的真实事件顺序、持续高负载的延迟分位数，以及把运行／提交作为独立空间节点的交互。当前使用局部面板和既有成果引用完成业务闭环。发现、保护和恢复在执行器不可用时仍独立工作。
